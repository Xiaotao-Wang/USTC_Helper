# USTC BB 作业检查器（BB_HW_Checker）

浏览器扩展（Manifest V3，兼容 Edge / Chrome）。装上后，在中科大网络教学平台
`bb.ustc.edu.cn` 的**首页上直接内嵌一个面板**，用三个选项卡整理你的作业：
**未完成作业**、**已完成作业（已评分）**、**已完成未评分（待评分）**。

极简设计：**不弹窗、不后台提醒、不设刷新间隔、不需要填账号密码**。
它复用你浏览器里**已经登录**的 BB 会话，同源读取课程与成绩页，把作业整理到首页。

## 安装

1. 打开扩展管理页：
   - Edge：地址栏输入 `edge://extensions/`
   - Chrome：地址栏输入 `chrome://extensions/`
2. 打开「开发者模式」。
3. 点「加载解压缩的扩展」，选择本目录 `BB_HW_Checker`。
4. 用你平时的方式登录 BB（账号密码你自己输，插件不接触、不保存）。
5. 回到 BB 首页，顶部即出现「作业面板」。

## 面板说明

面板顶部一排三个选项卡，点一下即切换（**切换不重新请求**，数据一次抓取、本地分流）：

- **未完成作业**：尚未提交的作业。按 DDL 升序，无截止日期的排最后。
  状态标签 `逾期`（深红）/ `临近`（橙，24h 内）/ `待交`（红）/ `无截止`（灰），右侧显示 DDL 与倒计时。
- **已完成作业**：已提交**且已评分**的作业。按**评分时间倒序**（最新评分在前），
  左侧徽章显示分数（如 `10/10`，绿），右侧显示评分时间。
- **已完成未评分**：已提交但**老师尚未评分**的作业。按**提交时间倒序**（最新提交在前），
  徽章为 `待评分`（黄），右侧显示提交时间。

配色遵循「红 → 黄 → 绿」的交通灯语义：**红 = 待交（需行动）**、**黄 = 待评分（已交待批）**、
**绿 = 已评分（完成）**，一眼区分轻重缓急；导航与标题栏保持科大蓝。

其它：

- 每个选项卡上的数字 = 该状态的作业数。
- 点作业名可在 BB 中打开对应页面。
- 只抓「作业」类，忽略测试 / 测验 / 问卷；加权总计 / 总计行自动跳过。
- 「刷新」手动重新读取；**点击面板标题栏**即可展开 / 收起（无需单独的折叠按钮，标题右侧箭头指示状态，支持键盘 Enter / Space）。选项卡选择、折叠状态均本机记忆。
- 10 分钟内重复进入首页会复用缓存，减少请求；点「刷新」强制重读。

## 它如何工作（为什么少触发验证）

- 内容脚本在首页主内容框运行，用 `fetch(..., {credentials:'include'})` **同源**读取：
  - 门户课程列表页 → 解析出你**当前学期**的课程；
  - 每门课的 My Grades（我的成绩）页 → 解析作业、完成状态（已评分 / 已提交 / 未完成）、
    截止日期、评分 / 提交时间、分数。
- 状态判定以成绩行类名为准（`graded_item_row` / `submitted_item_row` / `upcoming_item_row`），
  时间取自 `lastactivity` 属性，截止日期取自 `duedate` 属性，均无需额外请求。
- 全程复用你已有的登录 Cookie，**不重新登录、不 logout、不清 Cookie**，因此不会额外触发登录验证。
- 若会话已失效（读到登录页），面板提示「请重新登录」，你手动登录一次即可。

## 解析校准（重要）

作业页解析基于 Blackboard Learn 9.1 通用结构 + 兜底启发式。若发现**漏抓 / 误抓 / 日期不对**：

- 当面板「未解析到作业」时，会出现「导出页面结构」按钮，导出 `bb-hw-structure.json`；
- 把该文件发给开发者，即可据此把选择器校准到你学校的真实页面。

## 隐私与安全

- 不收集、不保存、不上传账号密码（插件根本没有凭据存储）。
- 所有请求只发往你当前所在的 `bb.ustc.edu.cn`（同源）。
- 无后台 service worker、无通知 / 定时器权限；缓存仅用页面 `sessionStorage`，折叠状态用 `localStorage`。

## 目录结构

```
manifest.json          扩展清单（仅 content_scripts，无任何额外权限）
content/util.js        日期解析 / 格式化 / 倒计时 / 状态判定
content/parser.js      课程列表、作业条目、登录检测、结构诊断（DOMParser）
content/bb-inject.js   首页面板：同源抓取 → 解析 → 三选项卡渲染（未完成/已评分/待评分）
content/bb-inject.css  面板样式（命名空间 bb-hw-）
icons/                 图标
```
